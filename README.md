# PlagiProof – AI-Powered Plagiarism Detection System

PlagiProof is an AI-powered plagiarism detection and document authenticity verification tool designed to analyze and compare text documents securely in an offline environment. The system uses Natural Language Processing (NLP), Sentence Transformers, and cosine similarity techniques to identify semantic similarities between documents and provide detailed plagiarism insights.

## Features
- Supports TXT, PDF, and DOCX file formats
- Offline and privacy-focused document analysis
- NLP-based semantic similarity detection
- Sentence-level plagiarism identification
- Cosine similarity scoring
- Highlighted plagiarism visualization
- Real-time plagiarism percentage calculation
- User-friendly interface for document comparison

## Tech Stack
- Python
- Sentence Transformers
- Scikit-learn
- NumPy
- PyPDF2
- Python-docx
- Google Colab

## Methodology
1. Upload and extract text from documents
2. Preprocess and split text into sentences
3. Generate sentence embeddings using Sentence Transformers
4. Compute cosine similarity between sentences
5. Highlight plagiarized content and generate plagiarism score

## Objective
To provide a secure, efficient, and intelligent plagiarism detection system that promotes academic integrity and ethical content creation through advanced NLP techniques.
